# ARMORED KOALA 2 — AK2 DEMO

Three.js の手続き生成モデルで描画する、キーボード・マウス操作の TPS メカアクションです。格納庫で機体を構成し、15 区画の廃工場に出撃します。6 基の制御砲台を破壊して隔壁と搬出ゲートを開放し、脱出領域へ到達してください。警備ロボット 30 体、固定砲台 15 体は再出現しません。

## 起動

Node.js 22.12 以上（本作の検証環境は 26.5.0）。依存関係は完全なバージョンと `package-lock.json` で固定しています。

```sh
npm ci
npm run build
npm run dev -- --host 0.0.0.0 --port 5173
```

ブラウザーで `http://localhost:5173` を開きます。デスクトップ、WebGL、1280×720 以上を想定します。出撃・再開ボタンの明示的なクリックで Pointer Lock を取得します。取得失敗時は戦闘を停止し、再開ボタンから再試行できます。実行中に外部 API、CDN、モデル、画像、音源を取得しません。効果音も Web Audio で生成します。

```sh
npm test
```

`?seed=20260908` の形式で uint32 のシードを指定できます。未指定は 20260908。本作の戦闘・配置・経路は乱数を使用せず決定的で、シードは診断値として保持します。描画用の装飾と戦闘状態は分離しています。

## 操作

| 入力 | 操作 |
| --- | --- |
| WASD | カメラの水平面に沿う移動。斜め方向も同じ速度 |
| マウス | TPS カメラ・照準 |
| 左クリック長押し | 選択武器を連射 |
| 1 / 2 / 3 | マシンガン / ビーム / ハンドミサイル |
| Q を一度押す | 36 EN を一括消費する QB。0.15 秒噴射後、自動グライド |
| Shift を一度押す | グライド切り替え。開始・持続・旋回とも 0 EN |
| 左 Ctrl | グライド解除・慣性ブレーキ |
| Space 短押し | 接地時の通常ジャンプ |
| Space を 0.20 秒以上保持 | 飛行。上昇 8m/s、20 EN/秒 |
| Esc | 一時停止・ポインターロック解除 |

Q はキーを離しても成立した噴射を取り消しません。全キーを離しても QB の慣性と自動グライドは継続します。グライドは EN0 でも使用でき、接地中は最終消費から 0.75 秒後に回復します。停止は左 Ctrl、または Shift で解除して減速します。

FCS（本課題での正式名称は **Flight Control System**）は対象の現在位置を中央の円内に保つことで自動取得・ロックします。ロック後は偏差と重力を自動補正します。中央照準を補正マーカーへ手動で合わせる必要はありません。対象マーカーと補正照準マーカーを別々に表示します。ロック中でも天井・設備で弾道が遮られる場合があり、解が存在しない場合は直接照準と「補正解なし」を表示します。

ミサイルはロック完了が必要です。マシンガン・ビームは自由射撃もできます。銃口位置とカメラ位置を分離し、武器切り替えで残弾、EN、武器ごとの発射待ち時間をリセットしません。

## 構成と実装

FCS 3 種、ジェネレーター 3 種、脚部 2 種の全 18 構成を使用できます。初期構成は中範囲・均衡・2脚です。4脚はモデル自体を変更し、水平速度 0.8 倍、EN 回復 0.75 倍、ロック速度 1.5 倍を適用します。格納庫の数値は `src/config.js` の実効値です。

マシンガンの最小正実根は、重根を含めて微分多項式の区間分割と二分法で求めます。初速 100m/s、重力 18m/s²、寿命 2 秒を維持します。解析的位置更新と相対運動の連続衝突を使用し、発射後に対象へ追尾しません。ビームは現在位置への即時レイ、ミサイルは速度 45m/s の迎撃解と最大 120度/秒の誘導です。ミサイルは遮蔽時に最後の観測を保持します。

シミュレーションの更新幅は最大 1/120 秒。噴射終了・発射時刻などでさらに区間を分割し、新規弾には発射以降の時間だけを適用します。敵は独立した予告・バースト・警戒タイマーを持ち、カメラ表示に依存せず攻撃します。8 秒の記憶、60m 以内の通行可能な味方への共有、設備と味方を避ける移動を実装しています。Pause 中はシミュレーションを呼ばず、全状態を凍結します。

`window.AK2_BENCH.getSnapshot()` は `AK2-1.2-candidate` 形式の状態コピーを返す読み取り専用 API です。弾体に実際に設定した初速、現在の FCS 解、直近 32 射、全敵の実際の攻撃数を返します。ゲーム状態変更・無敵化・自動クリア機能はありません。

## ステージ設計

物理定義の正本は `src/stage.js`、詳細は [STAGE_DESIGN.md](STAGE_DESIGN.md) を参照してください。

15 区画は x=0..2400m に連続配置し、区画境界は床・壁・屋根・開口部で形成します。開始 x=10m、脱出領域 x≥2425m のため、飛行や QB を含めても最短経路には **2415m 以上**の幾何学的な下限があります。最短経路全体を数値最適化した値ではありません。全 15 区画を通過し、通常ジャンプで超えられない 8m の必須上昇が 6 か所あります。高度帯は 0/8/16m。3 か所の設備を囲む分岐は再合流し、環状経路も形成します。5 戦闘区画には 70×50m の設備のない戦闘面と 4 体の敵を配置します。

開始位置は実体のある L 字遮蔽内です。制御砲台 T02/T04/T06/T08/T11/T14 が対応する B01..B06 を開き、すべて破壊すると FINAL-GATE を開放します。残る敵の全滅は必須ではありません。ゲートの見た目と衝突は同じ定義から生成します。

### 敵・進行・状態

通常AIの警備ロボット2体（40/45m）＋固定砲台1体（50m）が、HP1000の静止プレイヤーを **7.891667秒**で撃破しました。実際に生成した弾の連続衝突45回から生じた結果で、HP減少の特別処理はありません。発射数は警備各20、砲台10。初動、バースト時刻、予告、偏差、遮蔽時の記憶・回り込み・再露出、味方回避、壁による弾遮断を別途確認しています。

Game統合試験では45体の安定ID、3武器の実ダメージ、切り替え時の待ち時間保持、0 ENグライド、6砲台と隔壁の対応、最終ゲート、HP0優先、一時停止、再出撃全初期化、コピー型診断値、直近32射の履歴を確認しました。進行試験はテストコードから敵の破壊・脱出位置を準備し、通常の開放・判定処理を使います。手動で最初から最後まで攻略した証拠ではありません。
