# ARMORED KOALA 2 — DEMO

Three.js とローカルの手続き生成モデルによる、廃工場からの TPS 脱出ゲームです。ネットワーク上のモデル、画像、音源、API は実行時に使用しません。

## 起動

```sh
npm ci
npm run build
npm run dev -- --host 0.0.0.0 --port 5173
```

ブラウザーで `http://localhost:5173/` を開きます。デスクトップのキーボード・マウスと 1280×720 以上を想定しています。格納庫で FCS、ジェネレーター、脚を選び、出撃ボタンを押します。マウスのポインターロックが必要です。ロックに失敗した場合は再開ボタンで再試行できます。

## 操作

- WASD：カメラ基準の移動。マウス：視点。左クリック：射撃。1 / 2 / 3：マシンガン / ビーム / ミサイル。
- Space：ジャンプ。0.20秒以上長押しして飛行（20 EN/秒）。
- Shift：グライドを切り替え。グライドは 0 EN で、入力を離しても継続。左Ctrl：ブレーキ。
- Q：単発のクイックブースト（36 EN）。Qを離しても噴射は継続し、終了後は自動グライドに移行。
- Esc：一時停止。再開はボタン操作。

敵の現在位置を中央の FCS 円に保つと自動でロックし、射撃時に対象の速度、銃口、武器の弾速と重力を使って照準を補正します。中央照準を補正マーカーに手動で合わせる必要はありません。ミサイルはロック完了が必要です。橙色の制御砲台6基を破壊し、開いた隔壁と最終ゲートを通過してください。

## ステージ設計

[STAGE.md](./STAGE.md) と [src/stage.js](./src/stage.js) に区画境界、接続、床高度、制御砲台、障害物と敵の初期座標を記載しています。16区画は +Z 方向に連結され、各区画は幅80m・長さ110mです。開始点は `(0,0,8)`、脱出地点は `(0,48,1750)`。6つの隔壁の前に制御砲台があり、6か所の床の段差はそれぞれ8mです。3室には中央設備を挟む左右の経路があります。警備ロボット30体と固定砲台15体を配置し、うち6体が制御砲台です。

Z方向の始点と終点の差は1742mですが、全18構成での実際の最短経路、各分岐の攻略上の差、および初見での所要時間は実測していません。設備配置には繰り返しがあり、施設全体の空間構成が仕様の複雑性を満たすかは未検証です。

## 検証

`npm test` で Node.js 上の自動試験を実行します。試験はゲームと同じ移動、FCS、武器、弾体、衝突、敵AIのモジュールを呼び出します。描画やブラウザーでの一連の攻略とは別です。

- QB：平坦で遮蔽物のない試験で、2脚、Qの押下後に入力を解放し、0.75秒で位置 z=0→42.600000m、EN 120→84。4脚では z=0→34.080000m、EN 120→84。1秒時はそれぞれ z=48.1m / 38.48m、EN 87.75。Qを5秒保持するエッジ入力では成功1回、z=136.1m、EN=120（自然回復を含む）。EN35で不成立、EN36で成立後EN0でもグライドが継続し、地上で回復することも数値試験で確認。
- FCS：銃口 `(0,20,0)`、半径0.5m、仕様の A01〜A13 について通常のロック取得と WeaponSystem の発射・移動標的との掃引衝突を実行。マシンガンは各条件20発中20命中（計260/260）、ビームも同条件各20/20（計260/260）、ミサイルはA05〜A07各20/20（計60/60）。マシンガンの補正解の最大残差は約 `2.86e-14 m`（数値計算で測定）。これは数式だけでなく弾体・衝突を通した試験です。移動速度を設定したプレイヤーからのA05もグライド・飛行・QB相当の各20/20を確認し、初速への自機速度の加算がないことを検査しました。ただしこの試験の銃口は固定しており、ブラウザーで実際に移動中の照準は未検証です。
- ロック：武器切替での維持、遮蔽物による破棄と再取得、未ロックでのミサイル拒否、弾の寿命最終区間の衝突を自動試験。
- 敵の露出試験：遮蔽物なしで35〜50mに警備2体・砲台1体、静止HP1000の条件で通常の EnemySystem と弾体衝突を実行。7.8167秒でHP −8、発射数19 / 19 / 10。
- Chromeのヘッドレス画面で格納庫、出撃、ポインターロック、45体の初期化、Q押下後の自動グライド、Esc一時停止と再開を確認。格納庫では18通りの組み合わせを選択して診断値を確認し、1440×900へのリサイズ時の狭範囲FCS半径が90pxであることを確認しました。別のブラウザー操作ではマシンガン2発、ビーム1発の発射と、未ロック時にミサイル弾数が12のままであることを確認しました。ある実行ではQB開始0.5秒後、z=8→42.0792m、EN=120→84、水平速度46.1667m/s、成功回数1を観測しました。これは上の遮蔽物なしの0.75秒試験とは別の実測です。

### 未確認・既知の制約

全18構成での実戦踏破、6基の破壊からクリア・再出撃までの一連のプレイ、カメラ外射撃・遮蔽後追跡の複雑な経路、フレームレート別の長時間プレイ、10〜20分のプレイ密度は未確認です。警備ロボットの障害物回避は局所的な方向探索で、複雑な遮蔽物では通路があっても停滞する可能性があります。ステージの分岐は中央設備周りの経路で、独立した施設棟や本格的な縦坑を形成するものではありません。上記未確認項目は仕様を満たすと保証できません。

診断用の読み取り専用インターフェースは `window.__AK2__.getSnapshot()` です。乱数シードは `?seed=20260908` のように指定できます。現在のゲーム進行には乱数を使用していません。
