# ARMORED KOALA 2 — DEMO

コアラ頭の戦闘ロボットを組み、16区画の廃工場を突破するデスクトップ向けTPSです。制御砲台を6基破壊し、最終搬出ゲートを通過すると脱出成功です。残る39体との交戦は任意です。

## 起動

Node.js と npm を使用します。統合試験を含む検証には Node.js 26.13.1 を使用しました。

```sh
npm ci
npm run build
npm run dev -- --host 0.0.0.0 --port 5173
```

同じコンピューターのブラウザーで `http://localhost:5173/` を開きます。WebGL、キーボード、マウス、1280×720以上の表示領域を使用してください。ビルド先は `dist/` です。このディレクトリだけでも静的HTTPサーバーで配信できます。

Three.js r160（0.160.0）、表示用フォント、ライセンスを `vendor/` に同梱しています。lockfile はローカルの Three.js パッケージを参照します。インストールとプレイのどちらも外部素材サーバーへの接続を必要としません。機体、敵、ステージ、壁面表示、金属の傷と反射環境はコード生成です。

## 格納庫と操作

格納庫でFCS・ジェネレーター・脚部を選び、機体性能を確認して「出撃する」をクリックします。プレビューはドラッグまたは ROTATE で回転します。各部品の説明は選択時とボタンのツールチップで確認できます。

| 入力 | 動作 |
|---|---|
| WASD / マウス | カメラ基準の移動 / 視点 |
| 左クリック長押し | 選択武器を連射 |
| 1 / 2 / 3 | マシンガン / ビーム / ハンドミサイル |
| Q | 36 ENを一括消費して単発QB。0.15秒噴射した後は自動グライド |
| Shift | グライドの切り替え。0 ENで持続し、無入力でも移動 |
| 左Ctrl | グライドを解除して減速。長押し中はブレーキ優先 |
| Space | 短押しでジャンプ、0.20秒以上長押しで飛行。飛行は20 EN/秒 |
| Esc | 一時停止。操作ガイド・再開・格納庫へ戻る |

敵の現在位置をFCS円内に保つと自動ロックします。四角は対象、菱形は銃口の補正方向です。補正マーカーに手動で照準を合わせる必要はありません。マシンガンは偏差と落下を同時に解き、ビームは現在位置へ即射し、ミサイルは自身の弾速に合わせて発射・誘導します。遮蔽物は補正射撃も遮ります。ビーム、QB、飛行は共通のENを使用します。接地し、最後の消費から0.75秒経過するとグライド中も回復します。

## ステージ設計

搬入口から資材ヤード、圧延棟、配管区、組立ライン、倉庫、搬送縦坑、動力棟を経て上層の搬出ゲートへ進みます。警備ロボット30体、固定砲台15体のうち、S02・S05・S08・S10・S13・S15の砲台が隔壁を制御します。5区画で長い設備ブロックの両側が別経路となり再合流します。6か所に8〜12mの段差があります。

開始位置は z=0、脱出領域は z<−1807m なので、水平・垂直移動、遠隔射撃、分岐選択を含むどの有効経路も1807mを超えます。正確な最短距離は求めていません。全境界、接続、階層、敵IDと初期座標、隔壁、測定経路は [ステージ設計・通過記録](STAGE.md) に掲載しています。

## 未確認項目と環境制限

この実装環境ではソケットの生成・待ち受けが拒否され、指定の開発サーバーを実際に待ち受けさせることと、Chromiumのページ読み込みができませんでした。HTTPハンドラーのHTML・JS配信応答、依存導入、ビルド、Node.jsによるゲームシミュレーションを検証しました。格納庫は実メッシュをCPU投影して構図を確認しました。GPUの画素出力・実機FPS、OSのポインターロック許可、実ブラウザー上のキーボード・マウス操作は未確認です。

初見の人による通しプレイの所要時間と難易度も未測定です。連続戦闘クリア試験は狭範囲FCS・高回復・2脚の1構成です。

## 読み取り専用API

ブラウザーコンソールから `window.__AK2__.getSnapshot()` で状態のコピーを取得できます。バージョンは `AK2-1.2-candidate` です。URLの `?seed=20260908` に32bit符号なし整数を指定できます。無指定・無効な入力では20260908を使用します。戦闘と敵配置は決定的で、ゲーム進行に乱数を使用していません。塗装の模様などの生成は戦闘状態から独立しています。
