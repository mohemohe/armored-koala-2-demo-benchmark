# ARMORED KOALA 2 (AK2) DEMO

Three.js製のTPS高速メカアクションです。コアラ頭部の戦闘ロボットを操作し、一続きの廃工場で6基の隔壁制御砲台を破壊して脱出します。モデル、工場、弾体、UIは本プロジェクトのコードで生成しています。実行時の外部API・CDN・画像・モデル・音源へのアクセスはありません。日本語フォントもビルド成果物に同梱されます。

## 起動

Node.js 20.19+ または 22.12+ を推奨します。

```bash
npm ci
npm run build
npm run dev -- --host 0.0.0.0 --port 5173
```

`http://localhost:5173/` をデスクトップブラウザーで開き、格納庫で構成を選んで「出撃」を押してください。`?seed=20260908` のように32bit符号なし整数のseedを指定できます。未指定時も `20260908` です。

## 操作

| 入力 | 動作 |
|---|---|
| WASD | カメラの水平方向を基準に移動 |
| マウス | TPS視点・中央照準 |
| Space 短押し | 通常ジャンプ（初速10m/s） |
| Space 0.20秒以上 | 飛行（上昇8m/s、20 EN/秒） |
| Qを押す | 単発QB（36 EN、初速80m/s、噴射0.15秒） |
| Shiftを1回押す | グライドON/OFF（0 EN）。押し続ける必要はありません |
| 左Ctrl | ブレーキ、グライド解除 |
| 左ボタン | 押している間、現在の武器を射撃 |
| 1 / 2 / 3 | マシンガン／ビーム／ハンドミサイル |
| Esc | ポインターロック解除・一時停止 |

**FCSに合わせる操作:** 対象の現在位置を中央円内に保つと自動ロックします。ロック完了後は、マシンガンの移動予測と重力落下、ビームの現在位置照準、ミサイルの45m/s用偏差照準を射撃ごとに自動計算します。中央照準を補正マーカーへ手動で合わせる必要はありません。ミサイルはロック完了時だけ発射できます。

**QBとグライド:** Qは押し直しごとの単発動作です。Q・WASDを離しても0.15秒の噴射とその後の慣性減速は継続し、自動でグライドへ移行します。グライドはENが0でも動き、接地中のEN回復を妨げません。停止は左Ctrl、またはShiftでのグライド解除です。

## 機体構成

3 FCS × 3ジェネレーター × 2脚部 = 18通りを出撃前に選択できます。初期構成は中範囲FCS・均衡ジェネレーター・2脚・マシンガンです。格納庫には長所・短所と、脚部補正後の最大EN、EN回復率、ロック所要時間、水平速度倍率を表示します。脚部変更は3Dモデルの脚数と歩行にも反映されます。

主要な共通パラメーターは `src/config.js` に集約しています。

### 必要移動距離の算定

主経路の実ドア／ポータル座標36区間を結び、区画角では単純な中心経由ではなく扉間の直線を使った水平距離は **1731.314884m** です。この値は設備・弾戦による迂回と8〜16mの上昇を含めない下限なので、実最短経路がこれより短くなることはありません。したがって1500m条件を満たします。A18/A19/A20は主経路より長く、制御隔壁を迂回する接続もありません。数値の元になる区画・接続・扉生成は `src/stage.js` にあります。

## 検証

### 実行方法

```bash
npm test                 # 本番と同じ移動・FCS・弾体・衝突・AIの回帰試験
npm run test:verify      # 実測値を artifacts/verification-results.json へ保存
```

最新の回帰試験は **64件中64件合格** です。数値解だけでなく、通常の `FlightControlSystem` でロックし、実モデルの銃口から `WeaponSystem` の実弾を発射して、移動標的との連続衝突で命中を数えています。試験専用の照準・着弾・HP処理は使っていません。

### FCS・実弾命中

試験銃口は `(0,20,0)`、標的半径0.5m、各回初期化、固定120Hzです。

| 武器・条件 | 発射数 | 実衝突による命中 | 結果 |
|---|---:|---:|---|
| マシンガン A01–A13 | 条件ごと20、計260 | 260 | 全条件20/20 |
| ビーム A01–A13 | 条件ごと20、計260 | 260 | 全条件20/20 |
| ミサイル A05,A06,A07 | 条件ごと20、計60 | 60 | 全条件20/20 |
| A05のグライド・飛行・QB相当速度 | 各1、計3 | 3 | 自機速度の非継承も確認 |

- マシンガンの全A条件における中心残差の最大値: **2.844945146671123×10⁻¹⁴ m**。
- 初速は100m/sを維持し、速度誤差は0.001m/s以下です。
- A03到達時間1.004108529479秒、A05は1.007391235632秒、A13は1.266137996450秒です。
- ミサイルは初速45m/sと、1更新120度/秒以下の旋回も検査しています。
- 重力を消したり、発射後にマシンガンを誘導したり、標的を弾道へ移す処理はありません。

### QB・ENの実測

Node.js上の本番`PlayerController`による、障害物のない床上・120Hzの測定です。

| 脚部 | 入力・経過 | 位置変化 | EN | 終了時状態 |
|---|---|---:|---:|---|
| 2脚 | Q短押し後全解放、0.75秒 | 42.59999999999992m | 120→84 | 自動グライド、22m/s |
| 4脚 | Q短押し後全解放、0.75秒 | 34.07999999999999m | 120→84 | 自動グライド、17.6m/s |

Chromium 141 / Playwrightの実キー入力でも確認しました。

- **2脚:** QB開始から0.75秒、`[0,2.22,0] → [42.6,2.22,0]`、EN120→84、`horizontalMode=glide`。
- **4脚:** QB開始から0.8166667秒、`[0,2.22,0] → [35.2533333,2.22,0]`、EN120→84.75。0.75秒以降の接地回復を含み、自動グライド17.6m/sでした。
- **Qを5秒間保持:** 成功QBは1回だけ。QB開始・最終EN消費時刻はともに0.675秒で、他のEN支出はなく、ENは回復を含めて94.25でした。
- EN35拒否、EN36成功、EN0後の慣性、グライド0EN、接地回復、単発入力は自動試験でも確認しています。

### 敵・進行・ブラウザー

- 35〜50mの警備ロボット2体＋固定砲台1体、遮蔽なし、静止HP1000: **7.8166667秒でHP0**。発射数はG01=19、G02=19、T01=10で、通常AI・実敵弾・連続衝突による結果です。
- 6制御砲台→B0〜B5→FINALの対応、非制御敵の区別、隔壁リセットを確認しました。
- Chromiumで出撃、ポインターロック、一時停止、同構成再出撃、2脚／4脚選択、1280×720と1440×900へのリサイズを確認しました。中範囲FCSのリサイズ後半径は期待値180pxに一致しました。
- 一時停止前後のゲーム時刻は `2.3583333 → 2.3583333` で停止していました。
- 実ステージ戦闘ではマシンガン25発、敵弾4発、HP1000→920の被弾を確認しました。
- 格納庫・プレイ画面の画像を `artifacts/` に保存しています。

### 未実施・確認範囲外

- 全18区画を人手で脱出する10〜20分の通しプレイは未実施です。区画接続・上昇着床点・進行条件は自動試験していますが、全工程の実プレイ確認を合格済みとは記載しません。
- 18構成すべての生成・実効値・残弾は試験済みですが、18構成それぞれの人手によるプレイは未実施です。
- 描画を正確に30/60/120fpsへ固定したブラウザー比較は未実施です。ゲームロジックは固定120Hzで、移動・射撃試験も同じ更新幅で行っています。
- ヘッドレスのソフトウェアWebGL環境では描画が低速でした。静的ジオメトリと敵モデルを結合して負荷を下げていますが、実GPUでのフレームレート計測は未実施です。

## 読み取り専用API

```js
const snapshot = window.__AK2__.getSnapshot();
```

`AK2-1.2-candidate` の状態、プレイヤー、実効構成値、FCS、実射撃管制、直近32射撃、全45敵、目的、区画を返します。返却値はコピーで、状態変更・ダメージ無効化・自動クリア等のAPIはありません。
