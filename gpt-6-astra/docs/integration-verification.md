## 通常のゲーム処理を使用した数値・衝突検証

モックの命中結果ではなく、ゲームが使用する同じシミュレーション関数を Node.js から実行した。

- QB: 単発入力・入力解放・慣性・無料グライド、EN境界、30/60/120Hzの位置とEN一致。
- 本番入力アダプターへ Q の押下1回と99回のリピートを与え、5秒間保持しても QB 成功は1回。詳細は `movement-verification.md`。
- マシンガン A01〜A13: 半径0.5mの標的、通常のFCS取得を経由し、各20/20、計260/260命中。最大中心残差4.334×10^-11m。
- ビーム260/260、ミサイルA05〜A07で60/60、グライド・飛行・QB中の射撃60/60。
- 見た目の銃口位置・方向と実際の発射を、2脚/4脚・3武器・5方向で照合。
- 本編ステージの制御砲台へ実際に通常ビームを6射して破壊。対応する隔壁の描画と衝突だけが解除され、他の隔壁は維持。
- 警備2体＋砲台1体の通常AIと実弾衝突で、静止HP1000を7.8秒で撃破。
- 本編地形の6上昇×18構成=108回の飛行と着地を実施。最低残EN50.167。
- 本編地形の全17区画を通る経路を実体の移動衝突で走査。経路長2100.002m。これは最短経路を測定した値ではない。最短経路の下限1912mはスタートと脱出領域の実座標差から証明する。

## 未実施・既知の制約

- 使用した内蔵ブラウザでは canvas の `requestPointerLock` が `undefined`。仕様に従い、操作不能な状態では戦闘を進めない。外部 Chrome 接続もタイムアウトしたため、マウス取得に成功するブラウザでの実戦操作、Esc→再開、フォーカス喪失、物理キーを5秒保持する試験は未実施。
- Node.js の入力アダプター試験を、OS/ブラウザを含めた物理入力試験の実績としては扱わない。
- 通常の敵AIと戦いながら開始から脱出まで生存する10〜20分の通しプレイ、所要時間・難易度の人間による評価は未実施。経路と戦闘は個別に実処理で検証したが、通しプレイの代わりではない。
- 画面内の実FPSやGPU負荷の長時間計測、複数ブラウザ・複数端末の互換性試験は未実施。
- BGM・効果音は実装していない（任意仕様）。

`window.AK2_BENCH` は読み取り専用の snapshot のみ公開する。テストのための無敵化・テレポート・ダメージ直接操作・自動クリアは公開していない。
